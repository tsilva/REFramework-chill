REFramework-chill is an experimental [REFramework](https://github.com/praydog/REFramework)
fork focused on comfort when playing Resident Evil 7 in VR. It targets the older
DX11, non-ray-tracing TDB49 build.

## Install

1. In Steam, open the game's **Properties → Betas** and select `dx11_non-rt`.
2. Follow the [mod file instructions](docs/reframework-chill-guide.md#2-install-the-mod-files)
   to back up existing files and install the matching package.
3. Launch the game and check the [recommended setup](docs/reframework-chill-guide.md#recommended-setup).

The guide lists the comfort defaults, tested compatibility, and troubleshooting.

[REFramework-chill installation and comfort reference](docs/reframework-chill-guide.md).
